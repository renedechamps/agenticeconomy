RA-1.0 Conformance Test Harness

Reproducible conformance suite for Settlement Neutrality (Paper 2 §8.6).

Paper: Two Economies, Not One (arXiv v2)
Language: Python 3 (no external dependencies)
Run time: ~1 second
License: CC BY-SA 4.0

What this is

The Reference Architecture v1.0 (RA-1.0) implements the abstract settlement layer specified in Paper 2 §8.5 (formal properties SN1–SN5). This repository contains the conformance test harness — six tests (CT1–CT6) that verify a settlement layer satisfies the formal properties across multiple communication protocols and substrates.

How to run

# Run the conformance suite
python3 conformance_harness.py

# Output: 6/6 tests passed → settlement-neutral-conformant (v1.0)
# JSON results written to conformance-results.json

Adding a new substrate

The harness defines a Substrate Adapter API. New substrates can be tested by implementing the API and re-running the suite. Adding a new substrate adapter triggers automatic re-execution of CT1–CT6 against the new substrate.
