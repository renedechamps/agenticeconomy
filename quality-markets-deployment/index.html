Quality Markets Deployment Kit

Reproducible Monte Carlo simulation + k_conv calibration backing Paper 3.

Paper: The Oracle Problem in Autonomous Agent Commerce (arXiv v2)
Language: Python 3
Run time: ~10 seconds
License: CC BY-SA 4.0

What this is

This repository contains two reproducible simulations backing Paper 3:

  • Quality Markets Monte Carlo (Paper 3 §5.5ter, Table 5) — 1,000 verifiers × 90 days × 3 parameter regimes (base, low-detection, high-bribe). Validates Theorem 2 empirically.
  • k_conv calibration experiment (Paper 3 Appendix A) — 50,000 verifier-case pairs across 5 CRI bands. Measures the empirical conversion factor from CRI points to expected fee earnings.

How to run

# Quality Markets simulation
python3 qm_simulation.py

# k_conv calibration
python3 k_conv_calibration.py

Files

  • qm_simulation.py — Quality Markets Monte Carlo (6,571 bytes)
  • k_conv_calibration.py — k_conv calibration experiment (6,662 bytes)

Calibrated values

The k_conv experiment yields:

  • Per-case k_conv: 0.003 fee-equivalents per CRI point
  • Lifetime k_conv (~100 cases): 0.30 fee-equivalents per CRI point — the value used in Theorem 2
  • Linear model: fee_per_case = 0.085 + 0.00029 × (CRI − 50)
  • 95% CI: [0.0026, 0.0033] per case

Reproducibility seeds

  • Quality Markets: 0x5142
  • k_conv calibration: 0x4B43

Path to Production

Paper 3 §9.3 specifies a 60-day implementation path for Quality Markets in a new marketplace. The simulation parameters in this repository correspond to phase F2 (quorum N=3, treasury subsidy active). Phase F0–F4 transitions are governed by metrics defined in Paper 3 §9.1.
